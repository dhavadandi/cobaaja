# DSS Dashboard for NTT

  This is a code bundle for DSS Dashboard for NTT. The original project is available at https://www.figma.com/design/dss-dashboard-ntt.

## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

## Deploying to Vercel

  Run `npx vercel` to deploy to Vercel.
